# ゴールデンスライド(品質の正解)

エンジンの制約を外し、python-pptx でユーザーのマスタ上に**直接**組んだスライド。
これが品質の正解であり、高速エンジン(`public/layout.js`)はこれを再現することを目標にする。
順番は「①正解をレビューで固める → ②エンジンをこの正解の再現に作り替え、正解との一致で品質を測る」。

- 生成: `python scripts/make-golden.py`(既定マスタ: `~/Documents/プロジェクトアプローチ.pptx`)→ `docs/golden/golden-v2.pptx`。`--only 3,7` で一部だけ
- 書き出し: `powershell.exe -File scripts/ppt-export-file.ps1 docs/golden/golden-v2.pptx debug/golden-v2 1920`(PowerPoint 自身の描画)
- v1 の生成器は `scripts/make-golden-v1.py` に残してある(比較用)
- `*.pptx` はマスタ(社内テンプレート)を含むため **git に入れない**(`.gitignore`)。スクリプトだけを管理する

題材は架空の中堅部品製造 X 社(売上 480 億円)の収益改善。数値はすべて評価用の架空データで、25 枚が一つの案件(提案 → 診断 → 設計 → 実行 → 報告)を通しで表す。

## 設計原則(v2。レビューで更新する)

### 版面と文字
- タイトルは**メッセージ**(結論 + 数値)で 2 行まで。Georgia 20pt。プレースホルダ `32,30,896,58`。
- リードは 1〜2 行。タイトルの根拠か「何をどう整理したか」。Arial 13pt、`32,92,896,32`。
- 本文域は `y 128〜488`。**行高は「残り高さ ÷ 行数」で計算し、下を空けない**(`rows_fill` / `cols_fill`)。出典は `y 494` に 8pt 灰。
- 文字階層: 見出し 13 太字 / 小見出し 11.5 太字 / 本文 10.5(パネル型は 12〜12.5)/ 補足 9 / 注記 8.5 / KPI 28。
- 箇条書きは本物のぶら下げインデント(`buChar` + `marL/indent`)。2 階層まで。太字の小見出し(`#…`)の前に 6pt の余白。

### 色(モノトーン + 強調 1 色)
- 帯・矢羽・行見出し・ツリーの箱は**灰階調が既定**(帯 = 濃灰 #404040、行見出し = #D9D9D9、地 = #F2F2F2)。
- 橙(マスタの強調色)は **1 枚に 1 つの強調**だけ: 推奨案の列、主系列の折れ線、最大要因の棒、クリティカルパス、優先「高」、ゴールの数値、先行象限のバブル、人の判断が入る段。
- 進捗の状態だけは意味色(緑 / 琥珀 / 赤)を使う。

### 格子・表
- 行見出しは薄灰の箱、列見出しは濃灰の帯。左上の角は空ける。
- 罫は行の下に薄灰 1 本だけ。縦罫は引かない。ネイティブ表もセル罫を全部消して同じ見た目にする。
- 数値列は右揃え、文字列は左、見出し帯は中央(1 列だけの見出しは左)。区切り行は結合セル + 薄灰。

### パネル
- 黒下線(1.5pt)+ 中央揃え 13pt 太字の見出し。2〜4 パネルは必ず等幅。
- 列挙は文字量で向きを決める: 1 項目が 2 行を超える長文は**縦**(行名の箱 + 横長の説明)、短文は**横**(パネル)。

### 図
- 折れ線・積み上げ・棒はネイティブグラフ(値ラベル、凡例は下、目盛線は薄灰)。主系列だけ橙、他は中灰。
- ウォーターフォールは積み上げ棒の透明ベース。始点・終点は濃灰、減少は中灰、増加は薄灰、最大要因だけ橙。
- 矢羽(ステップ)の下には**段ごとの内容だけ**を行で揃える。別の可視化を同居させない。
- スイムレーンは箱 104×36、判断は菱形、矢印は濃灰 1pt の直線。
- ツリーはコネクタ線を「親の右 → 縦の幹 → 子の左」で引く。

### 密度
- 1 枚に主図 + 補助(小表・要点帯・確認指標)を必ず置き、40pt 以上の縦の空きを残さない。
- 右列は「意味合い / 読み取り / 判断」の帯 + 太字の小見出し + 箇条書き + So what。
