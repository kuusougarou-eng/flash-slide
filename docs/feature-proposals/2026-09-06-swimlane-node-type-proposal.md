# 新Node型「roadmap/swimlane」提案(未実装・申し送り)

- 作成日: 2026-09-06
- ステータス: **superseded(2026-09-06)。** 新 Node 型は追加せず、[2026-09-06-composable-cell-grid-engine-plan.md](2026-09-06-composable-cell-grid-engine-plan.md) の `table{headShape:"chevron"}`(セル合成の格子の行見出しを縦矢羽にする属性)として実装済み。列ヘッダー無地の規律は維持。
- 関連: [../architecture/generation-pipeline.md](../architecture/generation-pipeline.md) §6.2

## 背景

添付された社内テンプレート例(「プロジェクトアプローチ」スライド)は、以下の構造を持つ。

- 左端に縦積みの矢羽(現状把握→構想想定→ロードマップ策定→将来像)を「行ラベル」として配置
- 各行の右側に3列(概要/主なタスク/アウトプット)のテキストセルを横につなげる、いわゆるスイムレーン表

現行の `public/layout.js` の Node型カタログには、これに一致する型が無い。

- `chevrons` は矢羽を**横並び**に配置し、各段の要点はその**下**に積む型で、縦積み+右側3列という構造とは向きが異なる。
- `table` は行ラベルが矢羽形状にならない(通常の文字ラベル)。

## 決定事項(2026-09-06 ユーザー確認済み)

1. **新しいNode型は追加する方向で確定。** 仮称 `roadmap`(または`swimlane`)。
   - 構造イメージ: `{"type":"roadmap","stages":[{"head":"現状把握","cols":["AI PoCの現状と課題を明確化", "ヒアリングと調査を通じて現状の把握を行う", "現状分析レポート"]}, …]}`
     (列見出し「概要/主なタスク/アウトプット」は`colHeaders`のような別フィールドで持たせる想定。詳細スキーマは実装時に設計する)
2. **列ヘッダーの色塗りは不採用。** 現行のデザイン規律「表ヘッダーは無地・太字・下に強調色の太罫」([layout.js:9](../../public/layout.js))を優先し、添付テンプレートの「オレンジ地に白文字」のヘッダー見た目は**再現しない**。
   - 理由: モノトーン+強調色1色という全体方針([CLAUDE.md](../../CLAUDE.md)のデザイン方針節)を、個別テンプレート由来の見た目より優先する判断。
3. **矢羽(段ラベル)自体の塗りは対象外の議論。** 既存`chevrons`型はもともと矢羽を`fillDark`/`accent`で塗って白文字にしている([layout.js:611](../../public/layout.js))。この規律は「表・グリッドのヘッダー」に対するものであり、矢羽形状のラベルには適用されない。新ノード型でも矢羽ラベルは塗りつぶし+白文字でよい。
